# 复盘
用 publish 命令记录实际发布时间，随后到约定窗口用 review 录入统计时间与实际值。偏离约定时点超过1小时的数据被工具排除正式对账；可以另做定性复盘，不改原预测窗口凑结果。
工具报告：中心估计相对误差（实际为0时为空，另报绝对误差）、是否落入区间、区间宽度、基线误差。不要只展示命中而隐去宽度。
report 汇总指定目录里所有有效正式记录；同平台/账号/指标/窗口分组，同一视频只计一个主预测；缺数据记录单独报待完成。报告全部样本，不能挑最准确案例形成整体准确率。
定性复盘记录：已观察事实、尚无法确认的解释、下一条只改变的一项实验。一次播放结果不能证明某个词或某个画面导致成功。
增长：关注变化和目标受众评论；获客：用户自愿提供的脱敏有效咨询、来源、报价与成交，缺失不填零。
经验进入 lessons.md 时标明样本ID、日期与不确定性。方法调整保留版本，以后续作品验证，不把旧数据拟合成绩当新预测能力。
