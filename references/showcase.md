# 录屏展示模式

用于把真实使用过程变成适合短视频录屏、截图和前后对比的结果。它不是独立能力，也不降低原流程的数据与证据要求。

## 进入与退出

用户说“我要录屏展示”“进入演示模式”或“输出适合截图”时进入。记录当前正在进行的内容，不另建虚构项目。用户说“退出演示模式”后恢复普通输出。

首次进入只回复一行：

> 已进入录屏展示模式。接下来每一步只保留一个核心结果，你可以直接截图。

然后立即执行用户当前任务，不额外介绍功能。

## 呈现规则

- 每次只展示当前步骤的一张主卡；下一步另起回复，避免长页面失去视觉重点。
- 主卡前不写寒暄、方法解释或“下面是”。卡片后只保留一个明确动作。
- 使用稳定标题、短句、Markdown 表格、粗体数字和少量固定图标。
- 单元格优先控制在两行以内；详细依据折叠为卡片后的最多三条说明。
- 不使用虚假的实时分析、加载动画、精确概率或未经验证的“精准预测”。
- 播放预测仍须满足历史样本与统计口径要求。没有数据时展示材料清单，不展示虚构播放量。
- 若内容适合多张卡，先输出最能推动下一步的一张；用户说“继续”再输出下一张。

## 五张展示卡

按当前状态选择，不要求每位用户从第一张开始。

### 1. 创作者定位卡

标题：`🧭 你的内容坐标`

| 项目 | 结论 |
|---|---|
| 你是谁 | 身份与真实经历 |
| 核心盈利受众 | 最可能购买的人 |
| 重点内容受众 | 主要持续吸引的人 |
| 延伸受众 | 可能关注或传播的人 |
| 核心内容主线 | 帮助谁，用什么经验，解决什么问题 |

卡片后只保留“下一步：确认或调整四象限词汇。”

### 2. 四象限与选题卡

先显示四格地图，再显示前三个候选。每个候选必须包含排名、选题、组合类型、来源象限、适合用户讲的原因和关键证据。排名依据是个人匹配、证据准备度、受众价值与当前目标，不能把排名称为爆款概率。

标题：`🏆 只有你更适合讲的选题`

| 排名 | 选题 | 组合 | 为什么适合你 | 关键证据 |
|---|---|---|---|---|
| 1 |  | 同象限/跨象限 |  |  |
| 2 |  | 同象限/跨象限 |  |  |
| 3 |  | 同象限/跨象限 |  |  |

卡片后固定表达其含义：“选择一个选题，完成你的初稿，再把文案发给我，我会审核。”

### 3. 文案诊断卡

标题：`🩺 这条文案离发布还有多远`

| 维度 | 得分 | 最关键判断 |
|---|---:|---|
| 开头力度 | /10 |  |
| 主题显化 | /10 |  |
| 个人证据 | /10 |  |
| 金句排布 | /10 |  |
| 观点重复 | /10 |  |
| 反馈延迟 | /10 |  |
| **平均分** | **/10** | **补材料 / 改稿 / 可以拍摄** |

紧接着展示一张三行操作表：文案位置、具体修改、必须出现的画面。完整诊断仍保存到 script-review.md；展示卡不取代完整记录。

### 4. 受众吸引判断卡

标题：`🎯 这条内容会先吸引谁`

| 受众类型 | 他们为什么停下来 | 触发内容 | 可能的下一步 | 判断强度 |
|---|---|---|---|---|
| 核心盈利受众 |  |  | 咨询/查看主页/保存等 | 强/中/弱/未知 |
| 重点内容受众 |  |  |  | 强/中/弱/未知 |
| 延伸受众 |  |  |  | 强/中/弱/未知 |

依据只来自创作者档案、选题、稿件和历史反馈。这是发布前受众判断，不推断无法从材料得知的年龄、性别或真实职业分布。发布后用评论、私信、咨询与成交反馈验证。

### 5. 播放预测与对账卡

继续使用 templates/prediction-card.md 和 templates/review.md。展示时把中心预测、预测区间、实际播放和相对误差放在最醒目的位置；方法、样本数、窗口和限制保留在下方，不能省略。

## 连续录屏建议

推荐演示顺序：一句自我介绍 → 内容坐标 → 四象限 → 三个选题 → 选择一个并粘贴初稿 → 六维诊断 → 修改稿 → 受众吸引判断 → 播放预测 → 发布后对账。

用户已经有档案、象限或稿件时直接从对应位置开始，避免为了录屏重复建档。
