# 会话续接与状态判断

每次使用都先读取内容工作目录中的 `content-forecast-data/profile.md`、`concept-map.md` 和 `index.md`（存在时）。根据记录和用户当前要求决定入口，不根据“第几次对话”决定流程。

用户明确提出补词、生成选题、审核文案、预测、发布或复盘时，直接进入对应模块，只补问完成该任务不可缺少的信息。

## 状态路由

| 当前状态 | 默认动作 |
|---|---|
| 没有创作者档案 | 请用户自我介绍，进入新用户建档 |
| 有档案，象限未确认 | 展示当前四格象限，邀请补充、删除、移动或确认 |
| 档案和象限已确认 | 简报当前内容状态，然后直接生成选题 |
| 用户要求补充或调整词汇 | 更新记录，展示更新后的四格象限，询问是否继续调整 |
| 已生成选题，用户尚未选择 | 重新展示候选，请用户选择 |
| 已确认选题，没有初稿 | 提醒用户完成初稿后发来 |
| 用户发送初稿 | 进入六维文案诊断 |
| 已诊断，用户发送修改稿 | 对照上次问题复查，判断是否达到可拍摄状态 |
| 修改稿达到可拍摄状态 | 询问是否进行发布前预测 |
| 用户选择预测但材料不足 | 索取过往文案、后台截图及必要口径信息 |
| 已锁定预测，尚未发布 | 展示锁定状态，等待发布信息；不重算原预测 |
| 已发布，未到统计窗口 | 告知目标统计时间和仍需等待的时长 |
| 已到统计窗口 | 录入实际结果并按固定模板复盘 |
| 用户开始一条新内容 | 创建新内容 ID，旧记录保留 |

## 回访状态简报

回访用户没有直接指定任务时，简短显示：

- 四象限各有多少个已确认词和待确认词；
- 最多列出三条进行中的内容及其下一步；
- 可执行入口：调整地图 / 生成新选题 / 继续某条内容 / 录入发布结果。

不要重新输出完整创作者档案，除非用户要求查看或档案发生重要变化。不要把欢迎语写成长篇说明。

## 直接输入的处理

- 用户直接贴文案：先在 index.md 寻找对应选题。能判断就进入诊断；不能判断只问对应哪个选题或是否创建新内容。
- 用户直接贴后台数据：寻找等待复盘或等待预测材料的内容。存在唯一匹配就继续；有多个可能对象才要求选择。
- 用户直接说“生成选题”：已有确认象限时立即生成；没有确认象限时先展示现状并只处理必要缺口。
- 用户说“继续”：从 index.md 中最近一条未完成内容的下一步继续；若有多条同等可能才列出供选择。

所有续接都以文件记录为准。对话记忆与文件冲突时指出差异，让用户确认后再更新记录。
