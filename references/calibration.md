# 历史结果校准

校准的目标是让未来判断更可靠，不是解释过去为什么“其实预测得没错”。

## 何时允许校准

同一平台、账号、指标和观察窗口至少完成 5 次正式发布前预测与到期复盘。单条结果只记录，不改规则。连续 3 次出现同方向偏差时可提出候选调整；没有连续偏差，也可在累计 10 条后进行一次周期检查。

## 先排除执行偏差

以下记录可复盘，但不直接用于修改预测规则：投流；统计窗口不一致；发布后大改内容；成片未执行锁定稿的核心证据；平台异常；同一作品保留多个主预测。

## 校准顺序

1. 按平台、账号、指标、窗口分组，禁止跨组借用结果。
2. 汇总全部有效记录：样本数、平均相对误差、平均绝对误差、区间命中率、平均区间宽度。
3. 判断方向：连续高估、连续低估、区间过窄、区间过宽，或没有稳定偏差。
4. 找到可重复条件，例如同一内容形式、象限组合或证据类型；不要根据一次爆款新增规则。
5. 写出候选规则、适用范围、依据样本 ID 和可能副作用。
6. 用全部历史记录重算。只有排序或误差优于旧规则，并且没有靠扩大区间制造虚假命中时，才建立新版本。
7. 新版本只用于未来内容；旧预测和旧版本永不回写。

## 校准记录格式

- 校准版本：
- 建立日期：
- 适用平台 / 账号 / 指标 / 窗口：
- 依据样本 ID：
- 发现的稳定偏差：
- 旧规则：
- 新规则：
- 历史重算结果：
- 预期副作用：
- 从哪个未来内容 ID 开始使用：

“预测更准”必须来自尚未参与规则制定的未来内容。历史重算结果只能称为回测结果。
